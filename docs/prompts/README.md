# Repositório de Prompts

Esta pasta contém a documentação dos prompts utilizados no servidor MCP.
A rastreabilidade das alterações pode ser consultada diretamente no histórico de commits do GitHub.

## Prompts disponíveis

| Prompt                | Objetivo                                           |
| --------------------- | -------------------------------------------------- |
| agendar-atendimento   | Iniciar e conduzir o fluxo completo de agendamento |
| consultar-agendamento | Consultar informações de um agendamento existente  |

## Histórico de alterações

As modificações realizadas em cada prompt podem ser visualizadas através do histórico de commits do repositório GitHub.
